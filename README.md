# Origens

Plataforma de delivery de baixo custo com gestão de estoque integrada, feita para fortalecer o pequeno comerciante local.

## O problema

As plataformas de delivery dominantes (como o iFood) cobram taxas altas dos pequenos comerciantes (~27% em média), concentram o relacionamento com o cliente e não oferecem nenhuma ferramenta de gestão de estoque. O resultado: o comerciante perde margem, perde controle do próprio negócio e ainda corre o risco de vender produtos que já estão em falta.

## A proposta

O Origens é uma plataforma de delivery com:

- **Taxa reduzida** (proposta de 8%, bem abaixo da média de mercado)
- **Conexão direta** entre cliente e comerciante
- **Gestão de estoque integrada** — quando um produto é vendido, o estoque é atualizado automaticamente, evitando venda de itens indisponíveis

Este projeto nasceu como parte do Projeto Integrador (tema *Informática e Economia*) da turma 208 do IFPI Campus Teresina Zona Sul, e é também um produto real em desenvolvimento pela Darkline.
